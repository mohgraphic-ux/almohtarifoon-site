# المحترفون — الموقع ولوحة الإدارة

موقع عربي من اليمين إلى اليسار لأكاديمية المحترفون، نادي المحترفون ومسبح المحترفون. مبني باستخدام React وVinext، مع قاعدة بيانات D1 ومكتبة ملفات R2.

## الإدارة

افتح `/admin` وسجّل الدخول، ثم استخدم رمز التفعيل الخاص المرفق خارج مجلد المشروع. يتم ربط حساب المدير مرة واحدة؛ جميع واجهات الإدارة تتحقق من الصلاحية على الخادم. لا توجد كلمة مرور افتراضية في الكود. يجب توفير `ADMIN_SETUP_KEY` كسر في بيئة التشغيل. الموقع منشور بصلاحية خاصة للمالك؛ تغيير الجمهور يتم عبر إعدادات الاستضافة.

- تعديل الهوية والألوان والشعار والعناوين والنصوص وبيانات الاتصال والخصوصية.
- تعديل محتوى وصور الصفحة الرئيسية.
- إضافة وتعديل وحذف الأقسام والصفحات، مع روابط مخصصة ومقاطع نصية قابلة للإضافة.
- إدارة الأخبار والمدربين ومعرض الصور والأسئلة الشائعة، وحالات النشر والترتيب.
- رفع الصور لمكتبة R2 واختيارها داخل المحرر.
- استقبال طلبات التواصل، متابعة حالتها، حذفها وتصديرها.
- سجل النشاطات وتصدير محتوى الموقع كملف JSON.
- الحفظ والنشر صريحان؛ تعارض نسخ المحتوى يُرفض لمنع فقد تعديلات جلسة أخرى.

الأسعار والمواعيد والفئات المتاحة تُعرف بالاتصال فقط. إرسال النموذج ينشئ طلب تواصل؛ لا يؤكد حجزاً ولا يرسل بريدًا تلقائياً. إحصاءات لوحة الإدارة مستخرجة من البيانات الفعلية ولا تتضمن زيارات وهمية.

## النصوص والصور الثابتة

كل زر وعنوان ووسم وصورة ثابتة في الموقع (القائمة، الأزرار، نموذج التواصل، الفوتر، عناوين صفحات المعرض والأخبار والإنجازات ومن نحن ومنصة المحترف، شعار النادي، صورة شاشة المنصة، صور أقسام الفريق) تُعدّل من لوحة الإدارة في تبويب **«النصوص والصور»**، مقسّمة حسب الصفحة، مع بحث وزر «رجّع الأصلي» لكل حقل.

- القيم الافتراضية في `lib/copy.ts`، وتُحفظ التعديلات ضمن محتوى الصفحة الرئيسية (`home`) بنفس آلية «حفظ ونشر».
- لإضافة نص جديد قابل للتعديل: أضفه إلى المجموعة المناسبة في `lib/copy.ts` واستعمله في المكوّن عبر `t('المفتاح')`.
- صور الواجهات لكل صفحة (المعرض، الأخبار، التواصل، الخصوصية، الإنجازات) في تبويب «الصفحة الرئيسية».
- أسماء الأقسام ونصوصها وصورها، الأخبار، الإنجازات، المعرض، الفريق والأسئلة الشائعة لها تبويباتها الخاصة.

## محتوى البداية

`lib/content.ts` يحتوي نسخة البداية ويُستخدم إذا لم يُحفظ المحتوى بعد. الأخبار التجريبية مميزة بوسم واضح. بيانات التواصل من ملفات المشروع وتحتاج مراجعة المالك. صور التدريب والشعارات من المجلد المرفق؛ صور السباحة التوضيحية مميزة. لا توجد ادعاءات بطولات أو اعتمادات تدريب غير مؤكدة.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث. ثبّت الحزم باستخدام `npm run install:ci`. أنشئ البناء باستخدام `npm run build`، ثم طبّق كل migration غير مطبقة فقط على قاعدة البيانات المحلية:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_lovely_random.sql
npm run dev
```

لا تعِد تنفيذ migration مطبقة. ملفات `.wrangler/` و`.sites-runtime/` وبيانات الاختبار محلية وغير منشورة. بيانات الإنتاج منفصلة عن بيانات المعاينة. المصادقة المحلية تحاكي حساب `local_seedy` فقط؛ محاكاة الدخول غير موجودة في بناء الإنتاج.

## الفحص

- `npx tsc --noEmit`
- `npm run build`
- اختبارات المتصفح في `qa/` استخدمت Playwright من بيئة Codex؛ عدّل مسار استيراده عند تشغيلها خارج هذه البيئة.
- تحقق من الإضافة والتعديل والنشر في جلسة أخرى، طلبات التواصل والحالات والحذف، رفع الصور، منع الوصول غير المخول، وعرض الموبايل.

## ملاحظات التشغيل

الموقع لا ينسخ ملفات المجلد الإداري إلى الإنترنت. يُرفع فقط الكود والوسائط المنتقاة في `public/media`. رمز التفعيل لا يُحفظ في المستودع ولا يُرسل للمتصفح. يمكن إزالته من بيئة التشغيل بعد تفعيل المدير. للترحيل إلى استضافة أخرى يجب توفير بديل متوافق لقاعدة D1 ومكتبة R2 ومصادقة Sites.
